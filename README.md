Cadastro de Usuários
Descrição

Aplicação web para cadastro de usuários, que possui preenchimento automático de endereço a partir do CEP e armazenamento dos dados no navegador para que não se percam ao recarregar a página.

Funcionalidades

Preenchimento automático de endereço (logradouro, bairro, cidade e estado) usando a API ViaCEP ao digitar o CEP.

Armazenamento dos dados do formulário no Local Storage, garantindo que as informações permaneçam preenchidas mesmo após recarregar a página.

Layout moderno com form à direita e título à esquerda, botão em azul escuro.

Validação básica dos campos (nome, email, CEP, número).

Tecnologias Utilizadas

HTML5

CSS

JavaScript (Fetch API, Local Storage API, ViaCEP)
